# Enterprise Office Network Design and Implementation

### Cisco Packet Tracer | Enterprise Networking | VLANs | ASA Firewall | NAT | DHCP | DNS

---

## Overview

This project is a simulated enterprise office network developed using **Cisco Packet Tracer** to demonstrate the design, implementation, and testing of a secure and scalable business network.

The network incorporates industry-standard networking concepts including **VLAN segmentation, inter-VLAN routing, DHCP, DNS, NAT, wireless connectivity, and firewall security using a Cisco ASA 5505**.

The topology consists of multiple departmental networks connected through a core switch and office router, with centralized network services and an external connection to a simulated ISP and Internet cloud. Both wired and wireless devices are supported, allowing users to communicate across the network while maintaining organized traffic flow and network security.

To validate the implementation, the network was tested using **connectivity verification, browser communication, and packet analysis with Wireshark**, demonstrating the successful operation of key networking protocols and services within an enterprise environment.
