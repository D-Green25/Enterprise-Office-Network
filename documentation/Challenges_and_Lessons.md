# Challenges and Lessons Learned

## Challenges

During development, several challenges were encountered:

- Configuring VLAN routing
- Troubleshooting ASA firewall connectivity
- Setting up NAT
- Connecting wireless devices
- Verifying communication between network segments

These issues were resolved through testing individual network components and troubleshooting each layer.

## Lessons Learned

This project improved understanding of:

- Enterprise network design
- VLAN implementation
- Routing concepts
- Firewall configuration
- NAT
- Wireless networking
- Network troubleshooting
- Packet analysis
