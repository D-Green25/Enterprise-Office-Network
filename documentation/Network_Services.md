# Network Services

## DHCP

DHCP was implemented to automatically assign network information to client devices.

DHCP provides:

- IP address
- Subnet mask
- Default gateway
- DNS server information

This reduces manual configuration and allows devices to easily join the network.

## DNS

DNS provides name resolution by translating hostnames into IP addresses.

This allows users to access services using names instead of remembering IP addresses.

## HTTP Web Server

An internal web server was configured to demonstrate application-layer communication.

Clients can access the server through a web browser using HTTP requests.

## Wireless Services

Wireless devices connect through an access point using secure wireless authentication.
